ОТЧЁТ ПО СОЦСЕТЯМ АФМ

Дважды щёлкните по файлу «Отчёт АФМ». Откроется окно и спросит, что сделать:
1 — собрать свежий отчёт по каналам АФМ
2 — дополнить файл, в который вы вставили ссылки
3 — настроить автоподсчёт в вашей таблице (делается один раз)


ВАРИАНТ 1. Свежий отчёт по каналам АФМ
--------------------------------------
Введите 1 и нажмите Enter.
Дальше спросит, сколько публикаций брать — нажмите Enter, возьмётся 100.
Подождите: телеграм собирается около минуты, инстаграм — несколько минут,
окно в это время не закрывайте.
Готовый файл сам сохранится на Рабочий стол и откроется.


ВАРИАНТ 2. Свои ссылки
----------------------
Так можно посчитать любые открытые каналы и аккаунты, не только АФМ.

1. Откройте файл-заготовку (или любой готовый отчёт).
2. На листе «Ссылки» в колонку «Ссылка» вставьте сколько угодно ссылок на посты,
   по одной в строку. Остальные колонки оставьте пустыми.
3. Сохраните файл и закройте его.
4. Запустите «Отчёт АФМ», введите 2 и нажмите Enter.
5. Перетащите файл прямо в окно программы и нажмите Enter.

Программа пройдёт по каждой ссылке, подставит дату, описание, регион,
просмотры и комментарии, и сохранит файл обратно.
Строки, где цифры уже стоят, не трогаются.


ВАРИАНТ 3. Автоподсчёт в вашей собственной таблице
--------------------------------------------------
Это делается один раз. После этого вы просто вставляете ссылки, а ваша
таблица считает всё сама: количество публикаций, просмотры, комментарии,
баллы, общий балл и место.

1. Запустите программу, введите 3 и нажмите Enter.
2. Перетащите в окно свою таблицу (ту, где регионы и баллы).
3. Программа создаст рядом копию с припиской «(автоподсчёт)».
   Ваш исходный файл не меняется.

Дальше работаете только с копией:

1. В ней появился лист «Ссылки». Вставляйте туда ссылки на публикации,
   в колонку «Ссылка», по одной в строку.
2. Сохраните файл и закройте его.
3. Запустите программу, введите 2 и перетащите этот файл в окно.

Программа пройдёт по ссылкам, определит регион и подставит просмотры и
комментарии. В вашей таблице цифры и баллы пересчитаются сами.

Если регион определился неточно, поправьте его на листе «Ссылки» в колонке
«Регион», там выпадающий список. Пересчёт произойдёт сразу.


ЧТО ВНУТРИ ФАЙЛА
----------------
Лист «Ссылки»     — публикации: ссылка, дата, регион, описание,
                    просмотры и комментарии.
Лист «Регионы»    — сводка: сколько публикаций по каждому региону и суммы метрик.
Лист «Справочник» — список регионов.

Регион можно поправить вручную — в колонке «Регион» выпадающий список.
Цифры на листе «Регионы» пересчитываются сами.


ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
------------------------
Mac пишет про неизвестного разработчика:
   правой кнопкой по файлу -> «Открыть» -> в окне ещё раз «Открыть». Один раз.

Windows показывает синее окно «Система защитила ваш компьютер»:
   «Подробнее» -> «Выполнить в любом случае». Так бывает у программ без платной подписи.

Пишет «телеграм не отдаёт этот пост по прямой ссылке»:
   это отдельное фото внутри альбома. Откройте пост в канале и скопируйте ссылку заново.

Файл не сохраняется:
   закройте его в Excel. Пока файл открыт, программа не может его переписать.

Пишет «не удалось проверить сертификат сайта»:
   так бывает в рабочей сети, где интернет идёт через шлюз организации.
   Программа сверяется с хранилищем сертификатов самой Windows, и обычно
   этого достаточно. Если сообщение осталось, попросите системного
   администратора прислать корневой сертификат организации (файл .pem или
   .crt), положите его в папку рядом с программой и назовите «сертификат.pem»
   (или certificate.pem). Программа подхватит его сама.


ЧЕГО ПРОГРАММА НЕ УМЕЕТ
-----------------------
Просмотры по инстаграму — инстаграм не отдаёт их без входа в аккаунт.
По телеграму собираются просмотры, по инстаграму — комментарии.
